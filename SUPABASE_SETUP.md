# Panduan Konfigurasi Supabase - Web Pengumuman Kelulusan

Ikuti langkah-langkah di bawah ini untuk menyiapkan backend Supabase agar sesuai dengan aplikasi React yang telah dibuat.

## 1. Buat Tabel `siswa`
Masuk ke [Supabase Dashboard](https://app.supabase.com/), buka **SQL Editor**, dan jalankan perintah berikut untuk membuat tabel:

```sql
-- Buat tabel siswa
CREATE TABLE siswa (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  nisn VARCHAR(20) NOT NULL UNIQUE,
  nomor_peserta VARCHAR(50), -- Tambahan: Nomor Peserta
  nama_siswa VARCHAR(255) NOT NULL,
  tempat_lahir VARCHAR(100), -- Tambahan: Tempat Lahir
  tanggal_lahir DATE NOT NULL,
  kelas VARCHAR(50) NOT NULL,
  status_lulus BOOLEAN DEFAULT FALSE,
  link_skl TEXT, -- Link Google Drive PDF
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- Tambahkan indeks untuk mempercepat pencarian login
CREATE INDEX idx_siswa_login ON siswa (nisn, tanggal_lahir);
```

## 2. Masukkan Data Contoh (Opsional)
Anda bisa memasukkan data uji coba melalui SQL Editor:

```sql
INSERT INTO siswa (nisn, nomor_peserta, nama_siswa, tempat_lahir, tanggal_lahir, kelas, status_lulus, link_skl)
VALUES 
('0081234567', '26-02-01-001', 'Ahmad Fauzi', 'Banyumas', '2011-05-26', '9A', true, 'https://drive.google.com/file/d/ contoh_id/view'),
('0087654321', '26-02-01-002', 'Siti Aminah', 'Purwokerto', '2011-06-15', '9B', false, null);
```

## 3. Konfigurasi Keamanan (RLS)
Agar aplikasi bisa membaca data tetapi tidak bisa mengubahnya secara sembarangan, aktifkan **Row Level Security (RLS)**:

1. Buka menu **Table Editor** > pilih tabel `siswa`.
2. Klik **RLS is disabled** (ubah jadi Enabled).
3. Klik **Create Policy** > **Select "Get started quickly"** > Pilih **"Enable read access for all users"**.
4. Klik **Save Policy**.

> **Catatan:** Untuk produksi yang lebih aman, Anda bisa menyesuaikan policy agar hanya bisa diakses menggunakan `anon key`.

## 4. Setup Environment Variables
1. Buka menu **Project Settings** > **API**.
2. Salin **Project URL** dan **anon (public) Key**.
3. Buat file baru bernama `.env` di folder root proyek Anda (D:\projek pribadi\pengumuman_skl\.env).
4. Tempelkan kredensial tersebut:

```env
VITE_SUPABASE_URL=https://xyzyourproject.supabase.co
VITE_SUPABASE_ANON_KEY=your-long-anon-key-here
```

## 5. Tips Google Drive (SKL)
59: Pastikan link PDF di Google Drive diatur ke **"Anyone with the link can view"** agar murid bisa langsung mengunduhnya saat mengklik tombol di web.
